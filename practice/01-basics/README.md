# 01: Basics

I use this module to stay comfortable with the everyday loop of tracking changes before touching branches or GitHub at all.

| Part | What it covers |
| --- | --- |
| [01.1: Exercise](01.1-exercise) | The guided walkthrough: create, stage, commit, diff, log |
| [01.2: Extra Practice](01.2-extra-practice) | Harder variations: partial staging, restore versus restore --staged, renames |
| [01.3: Self-Test](01.3-self-test) | Questions with no answers shown, to check what actually stuck |

## Why this matters to me

Every other Git workflow I practise in this repository (branching, rebasing, collaborating) builds on this loop. If staging and committing are not automatic for me yet, everything after this module is slower than it needs to be.
