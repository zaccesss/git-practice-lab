# 02: Branching

I use this module to practise isolating work on a branch instead of committing everything straight to `main`.

| Part | What it covers |
| --- | --- |
| [02.1: Exercise](02.1-exercise) | Create, switch, merge and delete a branch, both with `checkout` and `switch` |
| [02.2: Extra Practice](02.2-extra-practice) | Parallel branches, renaming, remote-only deletion, comparing branch history both ways |
| [02.3: Self-Test](02.3-self-test) | Questions with no answers shown, to check what actually stuck |

## Why this matters to me

Branching is what makes the issue-to-PR workflow I follow in [CONTRIBUTING.md](../../CONTRIBUTING.md) possible. I never commit anything meaningful straight to `main`, this is the isolation that makes reviewing and reverting my own work possible.
