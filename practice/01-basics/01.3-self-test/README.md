No answers here on purpose, if I cannot answer these from memory I go back to [01.1](../01.1-exercise) and [01.2](../01.2-extra-practice) rather than looking them up.

1. Explain, out loud or in writing, the three states a change moves through before it is part of history.
2. Without running a command, predict what `git status` will say immediately after I edit a tracked file but before I stage it.
3. Write out, from memory, the sequence of commands to create a file, stage it, commit it and view the resulting log entry.
4. What does `git diff HEAD` show? How is it different from a plain `git diff`?
5. Name two commands that undo an uncommitted change and explain when I would use one over the other.
6. If a file shows as modified in `git status` after I already committed it, what does that tell me about what happened between the commit and now?

## Pass criteria
