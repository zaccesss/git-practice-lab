# 10: Daily Workflow and My Real Aliases

Modules 01 through 09 practise Git and GitHub in their raw form. In practice I almost never type the raw commands, my [dotfiles](https://github.com/zaccesss/dotfiles) define a short alias for nearly everything here. I use this module to practise the actual daily loop, alias and all, then to spot where an alias is missing.

| Part | What it covers |
| --- | --- |
| [10.1: Exercise](10.1-exercise) | The full daily loop using real aliases from `dotfiles`, not raw commands |
| [10.2: Extra Practice](10.2-extra-practice) | Finding a genuine gap in my own alias set and working out how to close it |
| [10.3: Self-Test](10.3-self-test) | Questions with no answers shown, to check what actually stuck |

## Why this matters to me

The whole point of an alias is that I stop thinking about the underlying command. If I have to look up a step every time, the alias has failed. This module is where I notice that failure and fix it at the source, in `dotfiles`, not by working around it here.
