# 04: Rebase and History

I use this module to practise cleaning up my commit history before I share it, using the tools that rewrite history rather than the ones that add to it.

| Part | What it covers |
| --- | --- |
| [04.1: Exercise](04.1-exercise) | Squashing commits with interactive rebase, amending a message, amending content |
| [04.2: Extra Practice](04.2-extra-practice) | Reordering, splitting and dropping commits, rebasing onto an updated main, autosquash |
| [04.3: Self-Test](04.3-self-test) | Questions with no answers shown, to check what actually stuck |

## Why this matters to me

A messy, exploratory commit history is fine while I am working. Before I open a pull request, a clean history makes the diff easier to review and the log easier for me to read months later.
