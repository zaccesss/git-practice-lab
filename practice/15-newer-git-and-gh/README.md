# 15: Newer Git and GitHub CLI Commands

I use this module to keep up with what recent Git and `gh` releases added, so my habits do not stay frozen at whatever version I learned on. It was written against Git 2.54 and `gh` 2.102. I check `git --version` and `gh --version` before starting and update this module when either moves on.

| Part | What it covers |
| --- | --- |
| [15.1: Exercise](15.1-exercise) | Everyday `gh` additions: issue branches, sub-issues, watching checks, updating and reverting pull requests, checking rulesets |
| [15.2: Extra Practice](15.2-extra-practice) | Newer Git commands, background maintenance, release attestations and two Actions habits |
| [15.3: Self-Test](15.3-self-test) | Questions with no answers shown, to check what actually stuck |

## Why this matters to me

Most of these replace something I used to do in the browser or with a longer command. Learning one release's worth at a time is easier than discovering years later that a whole workflow has a one-line version.
