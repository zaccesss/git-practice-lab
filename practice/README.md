# Practice Modules

Ten modules, roughly in the order I worked through them. Each one is a folder split into three parts: an `.1-exercise` (the guided walkthrough), a `.2-extra-practice` (harder variations) and a `.3-self-test` (questions with no answers shown). Each module's own `README.md` explains why the topic matters to my workflow and links to all three parts.

| Module | Topic |
| --- | --- |
| [01-basics](01-basics) | Staging, committing, status and diff |
| [02-branching](02-branching) | Creating, switching and merging branches |
| [03-merge-conflicts](03-merge-conflicts) | Causing and resolving a real conflict |
| [04-rebase-and-history](04-rebase-and-history) | Interactive rebase, squashing, amending |
| [05-stash-and-cherry-pick](05-stash-and-cherry-pick) | Shelving work in progress, copying single commits |
| [06-remote-collaboration](06-remote-collaboration) | Fork, upstream, push and pull request from the outside |
| [07-github-features](07-github-features) | Issues, image attachments, labels, tags and releases |
| [08-github-actions](08-github-actions) | Writing a CI workflow from scratch |
| [09-advanced](09-advanced) | Reflog, bisect, worktrees, hooks and newer GitHub features |
| [10-daily-workflow-and-aliases](10-daily-workflow-and-aliases) | The real aliases I use daily plus finding gaps in them |

I do not need to work through these in strict order once the basics are solid, but each module assumes I am at least comfortable with the ones before it. `cats.txt`, my original practice file from before any of this existed, now lives in [00-cats-original](00-cats-original) rather than the repository root.
