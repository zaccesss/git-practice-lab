# 14.2: Extra Practice

1. **Sub-issues:** break one module's issue into sub-issues, one per part (exercise, extra practice and self-test). Watch the parent show its progress as each closes.
2. **Milestones:** create a milestone with a due date, add the module issues to it and read the progress bar on the **Milestones** page.
3. **Roadmap view:** add a start date and a target date field, then a **Roadmap** view. Drag an item to change its dates.
4. **Iterations:** add an **Iteration** field with one-week iterations and plan the next week's modules into the current one.
5. **Draft items:** add a quick draft item for an idea, then convert it into a real issue once it is worth doing.
6. **From the terminal:** list everything with `gh project item-list <number> --owner "@me"` and read the JSON form with `--format json`.
7. **Clean up:** close the project from its settings once I no longer need the practice board. Deleting it with `gh project delete <number> --owner "@me"` also works.
